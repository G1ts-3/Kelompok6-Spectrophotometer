Panduan singkat

Nyalakan UPS → alat → UPC, lalu buka software. Ketik 246,5 nm untuk Standar/Sampel 1 atau 248,0 nm untuk Standar/Sampel 2, lalu tekan Terapkan λ; seri dipilih otomatis tanpa memilih larutan lebih dulu. Untuk mengganti λ, klik Atur / ganti λ, ketik angka lain dari kedua seri, lalu Zero blanko ulang. Pasang standar 0 ppm atau sampel, tekan Zero blanko (aquades menjadi referensi), lalu START ukur. Deret standar terpasang berurutan; lihat kurva pada tab Kurva kalibrasi. Sampel sendiri dapat ditambahkan di baki kiri. Isi bobot positif dan, jika perlu, Abs manual di komputer; Abs manual wajib untuk sampel sendiri. Input manual menjadi titik acuan kurva ilustratif dan diberi label dalam riwayat. Progres sumber cahaya → monokromator → kuvet → detektor terlihat selama pembacaan. Selesai praktik: catat log book, tutup software, shutdown UPC, matikan alat, lalu UPS. Penyiapan larutan dan pembilasan kuvet dilakukan di laboratorium nyata.

Urutan daya: UPS → alat → UPC.
