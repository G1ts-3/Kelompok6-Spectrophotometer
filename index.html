PANDUAN

Langkah penggunaan

A. Persiapan

  1. Siapkan kebutuhan analisis: larutan blanko (aquades), standar, dan sampel.
  2. Hubungkan kabel power ke sumber listrik (pada simulasi, kabel sudah tersambung di belakang alat).
  3. Nyalakan UPS dengan menekan tombol ⏻ UPS.
  4. Nyalakan alat Cary 100 dengan tombol daya pada alat.
  5. Nyalakan CPU komputer dan monitor. Urutan daya: UPS → alat → CPU.

B. Mencari panjang gelombang maks (Scan)

  1. Klik ▶ Buka Cary WinUV pada monitor dan tunggu hingga alat berstatus online.
  2. Pilih Seri 1 atau Seri 2 pada layar monitor, lalu klik START scan λmaks. Kurva Abs terhadap panjang gelombang digambar; puncaknya menjadi λmaks (seri 1 otomatis 246,5 nm, seri 2 248,0 nm).
  3. Isi kedua kuvet dengan blanko aquades (kuvet merah di belakang), lalu klik 01 · Zero blanko.
  4. Ganti kuvet depan (abu) dengan salah satu standar dari baki Ganti kuvet, lalu klik 02 · START ukur.
  5. Tunggu proses scanning selesai. Spektrum dan puncak serapan tampil pada tab Spektrum.

C. Konsentrasi (kurva kalibrasi dan sampel)

  1. Ukur deret standar 0, 5, 10, 15, 20, 25 ppm (mg/L) satu per satu dengan Zero blanko lalu START ukur.
  2. Buka tab Kurva kalibrasi. Pastikan regresi linear memenuhi R² ≥ 0,9500.
  3. Pasang sampel, isi bobot sampel (g), lalu klik START ukur untuk memperoleh konsentrasi.
  4. Lihat semua hasil pada tab Riwayat.

D. Mematikan alat

  1. Catat kejadian pada log book alat dan tanda tangani dengan nama jelas.
  2. Tutup software (tombol × pada jendela), lalu matikan komputer (shutdown CPU).
  3. Matikan alat Cary 100, kemudian matikan UPS. Urutan: CPU → alat → UPS.
  4. Lepaskan kabel dari sumber listrik kecuali kabel UPS, rapikan area kerja dan kursi.
  5. Keringkan kuvet (kuarsa dan kaca) dengan membilas etanol lalu aseton, balikkan pada posisi aman hingga kering sempurna.

Tip: klik Kenali bagian ⓘ pada model 3D untuk mengenal tiap bagian alat.

Panduan singkat

Nyalakan UPS → alat → CPU, lalu buka software. Pilih Seri 1 atau Seri 2 pada layar monitor, lalu tekan START scan λmaks: kurva Abs terhadap panjang gelombang digambar dan puncaknya menjadi λmaks (seri 1 otomatis 246,5 nm, seri 2 248,0 nm). Untuk mengulang atau berpindah seri, klik Cari λmaks lalu Zero blanko ulang. Pasang standar 0 ppm atau sampel, tekan Zero blanko (aquades menjadi referensi), lalu START ukur. Deret standar terpasang berurutan; lihat kurva pada tab Kurva kalibrasi. Bobot sampel dapat diubah dan Abs manual bersifat opsional di komputer; input manual menjadi titik acuan kurva ilustratif dan diberi label dalam riwayat. Progres sumber cahaya → monokromator → kuvet → detektor terlihat selama pembacaan. Selesai praktik: catat log book, tutup software, shutdown CPU, matikan alat, lalu UPS. Penyiapan larutan dan pembilasan kuvet dilakukan di laboratorium nyata.
